POJO in C++


  struct pojo {
    std::variant<
      std::nullptr_t,
      bool,
      double,
      std::string,
      std::vector<pojo>
      std::map<std::string, pojo>
    > value;
  };

This is literally nlohmann::json (JSON for Modern C++) under the hood

POJO in C++


  • JSON for Modern C++ (nlohmann::json)
  • Boost.JSON
  • RapidJSON
  • Many others for other formats
  • Mutability
  • Ergonomics
  • A POJO that feels like a native part of the language

The Price of Mutability


  • Multiple allocations when building
  • Traversing is chasing pointers
  • Mutable POJOs are not evil
  • Choose based on how you select custom map or array types
  • Consider using custom allocators

The reality: most consumers never mutate

Most Use Cases for POJOs


  • Build once. Likely parsing text (JSON)
  • Traverse several times. Likely once
  • Which of you use a mutable POJO library and never mutate?
